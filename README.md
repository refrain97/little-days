# 小日子 · 生活手记

把做过的菜、路过的小店和一闪而过的念头收进一本手机手记。可以拍照、录音或写字，回看时按时间、类别、收藏或店铺查找。

## 打开手记本

使用 Node.js 22 或更高版本。网页使用浏览器原生模块，可以直接在本机预览。

```sh
npm run dev
```

打开 [本机预览](http://127.0.0.1:5173/)。同一 Wi-Fi 的手机可通过 `npm run dev -- --host 0.0.0.0` 访问电脑的局域网地址。手机上的录音、主屏幕安装和离线缓存使用 HTTPS；本机测试可使用 localhost。已有受信任证书时，可设置 `JOURNAL_TLS_KEY` 和 `JOURNAL_TLS_CERT`。

## 三个入口

- **手记**支持拍照、选图、录音、文字和备注。记录时可以选择「下次再来」「还行」或「不合口味」，在「微调」中更改分类、评分和店铺。卡片与时光轴都能打开完整手记。
- **吃点啥**从自己的菜、饮品和到店记录找灵感。有原话时会摘出当时写下的感受。点进一家店可以翻看历史评价、安排今天去，或加到以后想做的清单。每天 10:30 前默认打开早餐池。手记勾上「早餐」即可入池，也能单独塞一个点子。按快手、慢做或外买筛选，再抽签决定今天吃什么。
- **有空**从小愿望和喜欢的手记里挑主意。按宅家或出门筛选，完成后归档，也可以记下这次体验。生日和纪念日会提前 14 天出现准备事项，到当天再出现祝福或庆祝事项。

手机底栏右侧、桌面标题旁的麦克风可直接打开「语音速记」。点「完成」后能看见准备存入手记或有空清单的内容，点「微调」可更改去向和字段。支持的浏览器可使用中文语音识别，文字入口也能配合 iPhone 键盘听写。

在「我的小天地」选择动物贴纸，共享内容会显示记录者头像。点手记下方的回应就能盖章，再点撤回，右边的省略号可选其他回应。本阶段新增的早餐点子、已定早餐与贴纸回应保存在当前浏览器的 IndexedDB，尚未跨设备同步。

## 保存和共享

手记正文和附件保存在当前浏览器中。首次打开有内置示例，可在「我的小天地」隐藏。要与另一个人共用，将两台设备连接到同一个私有 GitHub 数据仓库。「一起看」用于共享，「仅自己」的内容保存在当前设备。已共享内容改为私密并同步后，当前云版本会撤回，旧 Git 历史与已留存的备份仍可能包含原内容。

在「我的小天地 → 私人手记备份」可单独导出、合并恢复「仅自己」的文字、照片、原声和清单。下载到文件后确认保存，界面会显示上次备份日期。有私人内容且超过 14 天未备份时，手记页会出现提醒。整本迁移仍可使用「完整备份」。GitHub 令牌与 AI 密钥需在各设备上分别配置。

打开网页时先读取本机 IndexedDB。共享改动随本机保存进入待同步队列。断网可以继续记录，恢复联网后自动重试；遇到 401 时，在提示中点「更新 Token」即可补传。iPhone 可以拍照、在原话输入框用系统键盘听写，或录下原声。录音会探测本机支持的 MP4/AAC、WebM 等编码。

## 识别和整理

文字可在浏览器中提取标题、分类、食材、步骤和感受。需要 AI 识图、整理或转写时，在「我的小天地」配置支持相应输入类型的兼容接口。云 AI 只对「一起看」开放，主动操作后，界面会展示本次内容与接收服务，确认后才发送。服务不可用时，仍可保存原始记录。配置的接口须允许来自页面域名的浏览器跨域请求。

## 发布到 GitHub Pages

首次开发时先安装手机验收工具。Linux 可将第二条命令换成 `npx playwright install --with-deps webkit`。

```sh
npm ci
npx playwright install webkit
```

每次改版可在项目根目录运行这条命令。

```sh
npm run qa:mobile
```

脚本自动启动本机服务，在 390×844 的 WebKit 触屏视口检查三页滚动、横向溢出、底栏位置和两个录入弹窗。它还模拟键盘缩短可视区域，实际输入、点按保存，检查底页恢复滚动。它也会测试时段边界、早餐抽签、录音浮层与权限受限分流、头像和贴纸回应。验收截图保存在 `qa-screenshots/`。截图和测试记录只使用隔离浏览器中的示例内容。

`npm ci` 会为当前检出安装 Git 推送前检查，逐个验收将要推送的提交。若项目已有自定义 pre-push，请在原钩子中调用 `scripts/pre-push "$@"`，并传入 Git 提供的标准输入。GitHub Actions 发布前也会运行单元测试与手机验收，测试通过后才会部署。工作流的 `mobile-qa-screenshots` 附件保留 7 天。

以下命令可在本机预览发布构建。

```sh
npm run build
npm run preview -- --base /little-days/ --port 5188
```

打开 [仓库子路径预览](http://127.0.0.1:5188/little-days/)。构建输出在 `dist/`，包含网页、PWA 图标和内置示例照片。GitHub Pages 上传这个静态目录，无需常驻服务。公开代码仓、私有数据仓、手机配置和恢复步骤见 [GitHub 部署指南](DEPLOY_GITHUB.md)。
